# BulkReg – Changelog

All components carry the same release number: `VERSION`, both LotusScript libraries (`BR_VERSION` in BulkRegCommon, header of BulkRegAgents) and the header of every agent, `bulkreg.ini`, `server_mapping.csv`, the PowerShell helper, the Audit Viewer, the README and the Admin Guide (which reads `VERSION` when it is built). Check with `scripts\windows\bulkreg.cmd Versions`.
