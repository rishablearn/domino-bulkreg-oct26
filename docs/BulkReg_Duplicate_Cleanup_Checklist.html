BulkReg: Baseline and Duplicate Clean-up

Ops checklist. Order: 01 Preflight, 09 Reconcile, 11 Batch Manager, duplicates (12), 08 Repair mail, 04 Verify, 09 again.

Sources: PLAYBOOK-post-deploy-4.5.0.md sections 5 to 9, DEPLOY-4.5.0.md and the agent code. Nothing here has been run against Domino. Agent 12 was added after 4.5.0 and has not been compiled yet: do a dry run before any live run.

0Before you start

  • No batch is running on any machine. Agents 02 and 03 run on one machine at a time until this clean-up is finished.initials
  • bulkreg.ini: DryRun=1, PartitionCount=1 (partitioning off), no <PLACEHOLDER> left.initials
  • Libraries BulkRegCommon and BulkRegAgents re-pasted and compiled; agent BulkReg\12 - Remove Duplicates installed (shared agent, target None).initials
  • Backups of C:\BulkReg (locally encrypted disk) and of names.nsf taken. Restore path agreed.initials
  • No STOP.txt in BatchDir (agents refuse to run while it exists).initials

1Baseline (read-only)

  • 01 - Preflight Check on one machine. Expect no errors on config, servers, vault and log database.initials
  • 09 - Reconcile on one machine (leave the expected-users prompt empty, or give the CSV of users that should exist). Read RECON_<run>_summary.txt, then _gaps.csv, _duplicates.csv, _duplicate_ids.csv, _missing_mail.csv. Note the run ID:  initials
  • 11 - Batch Manager with the action empty, on every machine that ever ran BulkReg. Keep each BATCHSTATUS_<run>.csv. Note every batch that is not DONE_COMPLETE.initials

2Open, stopped or incomplete batches

  • On the machine that built each batch: 11 then RECOVER <batch id> (read-only). Read RECOVER_<id>_<run>.csv.initials
  • Act per state (table below). Resume a batch only on the machine that owns it, and confirm with the other operator that nobody is running it.initials
StateNext step
NOT_REGISTEREDRun 03 again on the owning machine (resumes), or REMAINDER <id> then review and run 03.

Other 11 actions (each needs YES): RESUME, REMAINDER, CLOSE. bulkreg Stop creates STOP.txt on that machine only: create it on every machine that is running.

3Duplicates

  • Review _duplicates.csv with the business owner. Rows: KEEP (stays), DO_NOT_REGISTER (unregistered duplicate: agent 12), REVIEW (second registered identity: manual AdminP decision, agent 12 never touches it).initials
  • _duplicate_ids.csv: IDFILE_MULTIPLE (run 09 on both machines, compare ids_listing.csv; keep the ID that is in the vault or was handed out, archive the others by hand), IDFILE_UNREGISTERED and VAULT_UNREGISTERED (do not register again; check the log and the vault first).initials
  • Confirm bulkreg.ini: DuplicateDeleteMethod =   (ADMINP / DIRECT / AUTO), DuplicateMustMatch=name,short,inet,first,last, DuplicateMaxDelete=25.initials
  • 12 - Remove Duplicates with DryRun=1. Input: RECON_<run>_duplicates.csv. Read DEDUP_DRYRUN_<run>.csv: WOULD_REMOVE rows are the plan, every SKIP_* row says why.initials
  • Handle skips: SKIP_NOT_FULL_DUPLICATE (a field differs: review by hand), SKIP_NEEDS_DIRECT / SKIP_AMBIGUOUS_NAME (flat or shared name: AdminP unsafe; decide on DIRECT after review), SKIP_IN_OPEN_BATCH (finish the batch first), SKIP_KEEPER_MAIL_MISSING (do Phase 4 first).initials
  • Approval: business owner has seen the WOULD_REMOVE list. Name:  initials
  • Set DryRun=0, run 12, type REMOVE. It stops after DuplicateMaxDelete removals: repeat dry run and live run for the rest.initials
  • Snapshots exist in <PasswordDir>\DEDUP_<run>\ (restricted folder, can hold password hashes). AdminP requests need a few minutes: check the Administration Requests database.initials
  • Set DryRun=1 again.initials
Stop and escalate (do not self-remediate) on a suspected security incident: unexpected certificates or IDs, a password or ID file outside its folder, or vault inconsistencies across many users. Create STOP.txt on every machine and contact the Domino or security owner.

4Registered, but no mail file

  • MailTemplate is set in bulkreg.ini on every machine that runs 08.initials
  • 08 - Repair Missing Mail Files with DryRun=1, scope empty or RECON_<run>_gaps.csv. Read <scope>_mailrepair_DRYRUN_<run>.csv (WOULD_CREATE).initials
  • DryRun=0, run 08, type REPAIR. Results should be MAIL_CREATED or CREATED_PENDING (AdminP still creating replicas).initials
  • 04 - Verify Registration and Vault on the owning machine. Repeat until: all IN_VAULT, MAILFILE_OK, REPLICAS_OK.initials
