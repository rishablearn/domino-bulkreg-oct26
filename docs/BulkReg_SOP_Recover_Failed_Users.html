SOP: Recover failed and missing users

One rule: the Domino Directory is the truth. Agent 13 - Recover Users compares it with the mail servers and fixes what is wrong in one run: it removes duplicates, creates missing mail files, replaces cut-off ones, and frees the users that 02 - Build Batch was silently skipping. It does not matter which machine or which release (4.5 or older) registered a user. Run it again as often as you like: it only does what is still missing and never overwrites a mail file.

The five steps

# Do Result
1 On each mail server run the listing script, copy the CSV to the BulkReg machine into C:\BulkReg\maillists\ Server file lists (read-only, 1 minute)
2 DryRun=1. Run 13 - Recover Users Counts on screen + RECOVER_<run>_plan.csv
3 Read the plan (Include=Y rows are fixed by 13; MANUAL rows need a person) Plan agreed
4 Pilot: add RecoverMaxCreates=10, DryRun=0, run 13, type RECOVER. Check 2 or 3 users. Then remove RecoverMaxCreates and run 13 again Duplicates removed, mail files created, stale batches closed. If it stops (slow server, time limit), run it again
5 Run 02 - Build Batch, review, 03 - Register Batch for the users still not registered. Run 13 once more (DryRun=1) 13 says nothing for this agent to do

Finish: hand over initial passwords from secure\ and delete them. Set DryRun=1.

What 13 does with each user

Finding Action
Unregistered full duplicate of a registered user (same name, short name, Internet address) Removed, after a snapshot (up to DuplicateMaxDelete, default 25 per run). Mail files, ID files and the registered user are never touched
Registered, mail file missing Created
Mail file is a tiny, cut-off file Replaced (only with RepairRemoveEmptyShells=1, only in a BulkReg mail folder)
Not registered, held back by an old open or stopped batch (older than 24 h) Batch closed, so 02 builds the user
Not registered, nothing holds it back Counted as ready for 02
Anything else (no mail item, server down, file with data but no design, recent open batch, no Internet address, doubtful duplicate) MANUAL: reason in the plan, you fix it

Why 02 "created nothing": 02 skips every user who is in an open or stopped batch file on that machine, who is a duplicate of a registered user, or who has no Internet address. The plan shows which of these applies to each user, and 13 closes the stale batches. After that, 02 finds the rest.

Two machines

Set once: Machine A PartitionCount=2, PartitionIndex=1. Machine B PartitionCount=2, PartitionIndex=2. Each handles its own half of the users.

  1. Same kit and same DirectoryServer on both.
  2. Dry run on both: "Directory users scanned" must be the same number. If not, wait for directory replication.
  3. Run both at the same time. A second run on the same partition is refused (log-database guard); if a machine crashed, answer Yes to the warning only when that run is really over.

If it is slow, or Notes hangs after hours ("too many handles" in NSD)

What the documentation says (and what it does not):

  • CreateFromTemplate returns before a large copy has finished (HCL reference). A loop that does not wait lets several big copies pile up on the server, and sets title and ACL on half-copied files.
  • There is no documented LotusScript switch to let AdminP create the mail file in the background; that exists only in the C API (NotesRegistration properties). So creating the file "like 03" (registration with CreateMailDb) is also client driven and is not expected to be faster. That is why 03 stays fast only with MailFileDeferred=1.
  • A single Notes client process that runs for 8 hours holds every handle it opens. Not confirmed from the NSD: the cause. See "Confirm it" below.

What agent 13 does about it:

  • Creates one mail file at a time and waits until its copy is complete (poll for the design every 2 s, RecoverCreateWaitSec), on the home server with the template opened on the same server. The three timings (SecExists, SecCreate, SecAcl) are in RECOVER_<run>_timing.csv.
  • Works in short sessions: stops cleanly after 250 mail files or 60 minutes (RecoverMaxCreates, RecoverMaxMinutes), and tells you: close Notes completely, open it again, run 13 again. Restarting the client is what releases the handles. A run is never meant to last 8 hours.
  • Releases every database and view object as soon as it is done, and reads the mail-file lists from CSV instead of opening each file.
  • Stops itself when the server is struggling (3 creates over 60 s in a row).

For the agents already in use, no code change needed: set MailCreateMaxPerRun=250 (08) and BatchSize=250 (02/03). Each run then ends by itself; close Notes, reopen, run again (03 and 08 resume). Create STOP.txt in BatchDir to end a run cleanly at any time.

Confirm it (so we fix the right thing):

  1. Run one session of 13 and open RECOVER_<run>_timing.csv: is SecCreate high? Then the server copy is the slow part (busy server, antivirus scanning the mail folders, backup or indexer running).
  2. Watch nlnotes.exe in Windows Task Manager (Handles, Memory) during a session. If handles climb steadily per mail file, send the NSD and RECOVER_<run>_timing.csv to HCL support with the Notes client version.
  3. Server side, run the client next to the servers (same LAN or a VM beside them) and outside backup windows.

If creating from the client is still too slow: the next step is a small server-side worker (an agent on each mail server that creates the files locally and works through a list in short runs). It needs a database on each mail server, an agent signed by an ID allowed to run unrestricted agents and create databases there, and a decision by the Domino security owner. Tell me if you want it built; it is not part of this release.

Stop and escalate

Create STOP.txt in BatchDir to stop cleanly. For a suspected security incident (unexpected certificates or IDs, a password or ID file outside its folder), do not fix it yourself: create STOP.txt and call the Domino or security owner.

Listing script, Linux mail server

#!/usr/bin/env bash
# bulkreg_list_mailfiles.sh - list the mail files of THIS Domino server for BulkReg agent 13 - Recover Users
#
# Run on each Linux mail server (read-only; it only lists files):
#   ./bulkreg_list_mailfiles.sh <data directory> <server name as in Domino> [output.csv]
#   ./bulkreg_list_mailfiles.sh /local/notesdata "DominoADMail/Demo"
# Output CSV (UTF-8):  Server,Path,Bytes,Modified     Path is relative to the data directory (mail1/smith.nsf)
# Then copy the CSV to the machine that runs BulkReg, into its MailListDir (default C:\BulkReg\maillists\).
# Covers the folder "mail" and "mail<number>" (mail1, mail2 ...). Other folders: set FOLDERS="mail mail1 mail2 hr".
# Not a replacement for Domino's own view of the files: it lists what is on disk. A file that is copied or
# half-written right now may show a small size; agent 13 opens small files to check them.
set -euo pipefail
DATA="${1:-}"; SERVER="${2:-}"; OUT="${3:-}"
[ -d "$DATA" ] && [ -n "$SERVER" ] || { echo "Usage: $0 <data directory> <server name> [output.csv]" >&2; exit 1; }
[ -n "$OUT" ] || OUT="maillist_$(printf '%s' "$SERVER" | tr '/ ' '--')_$(date +%Y%m%d-%H%M%S).csv"
DATA="${DATA%/}"
{
  printf 'Server,Path,Bytes,Modified\n'
  if [ -n "${FOLDERS:-}" ]; then
    for f in $FOLDERS; do [ -d "$DATA/$f" ] && find "$DATA/$f" -maxdepth 1 -type f -iname '*.nsf' -printf '%P\t%s\t%TY-%Tm-%Td %TH:%TM\n' | sed "s|^|$f/|"; done
  else
    find "$DATA" -mindepth 2 -maxdepth 2 -type f -iname '*.nsf' \( -path "$DATA/mail/*" -o -path "$DATA/mail[0-9]*/*" \) -printf '%P\t%s\t%TY-%Tm-%Td %TH:%TM\n'
  fi | awk -F'\t' -v s="$SERVER" '{ gsub(/"/,"\"\"",$1); printf "\"%s\",\"%s\",%s,\"%s\"\n", s, $1, $2, $3 }'
} > "$OUT"
echo "Wrote $OUT ($(($(wc -l < "$OUT") - 1)) mail files)"

Listing script, Windows mail server

scripts/windows/BulkReg_ListMailFiles.ps135 lines - click to open, then Copy
<#
.SYNOPSIS
  Lists the mail files of THIS Windows Domino server for BulkReg agent 13 - Recover Users (read-only).
.DESCRIPTION
  Run on each Windows mail server:
    powershell -ExecutionPolicy Bypass -File .\BulkReg_ListMailFiles.ps1 -DataDir D:\Domino\Data -Server "DominoADMail2/Demo"
  Writes  maillist_<server>_<time>.csv  (UTF-8, columns Server,Path,Bytes,Modified; Path relative to the data directory).
  Copy it to the machine that runs BulkReg, into its MailListDir (default C:\BulkReg\maillists\).
  Covers the folder "mail" and "mail<number>". Other folders: -Folders mail,mail1,hr
  Not run by its author on Windows.
#>
param(
    [Parameter(Mandatory)] [string]$DataDir,
    [Parameter(Mandatory)] [string]$Server,
    [string]$Out,
    [string[]]$Folders
)
$ErrorActionPreference = 'Stop'
if (-not (Test-Path -LiteralPath $DataDir -PathType Container)) { throw "Data directory not found: $DataDir" }
$DataDir = (Resolve-Path -LiteralPath $DataDir).Path.TrimEnd('\')
if (-not $Out) { $Out = "maillist_{0}_{1}.csv" -f ($Server -replace '[\\/ ]', '-'), (Get-Date -Format 'yyyyMMdd-HHmmss') }
if (-not $Folders) {
    $Folders = @(Get-ChildItem -LiteralPath $DataDir -Directory | Where-Object { $_.Name -match '^mail\d*$' } | ForEach-Object { $_.Name })
}
$rows = foreach ($f in $Folders) {
    $p = Join-Path $DataDir $f
    if (Test-Path -LiteralPath $p) {
        Get-ChildItem -LiteralPath $p -File -Filter *.nsf | ForEach-Object {
            [pscustomobject]@{ Server = $Server; Path = "$f\$($_.Name)"; Bytes = $_.Length; Modified = $_.LastWriteTime.ToString('yyyy-MM-dd HH:mm') }
        }
    }
}
$rows | Export-Csv -LiteralPath $Out -NoTypeInformation -Encoding UTF8
Write-Host "Wrote $Out ($(@($rows).Count) mail files)"

'=====================================================================
' Script Library : BulkRegRecover           (unreleased addition to 4.5.0 - see CHANGELOG "Unreleased")
' Purpose        : Agent  BulkReg\13 - Recover Users  ->  BR_RunRecover
'                  ONE agent that checks every user against the Domino Directory (single source of truth) and the
'                  mail servers, and repairs what is wrong, in this order:
'                    1. DUPLICATES      unregistered full duplicates of a registered user are removed
'                    2. MAIL FILES      missing mail files are created, cut-off (empty) files replaced
'                    3. STALE BATCHES   old open/stopped batch files that hide users from 02 are closed
'                    4. REMAINING USERS counted and explained; 02 + 03 then register them (nothing to configure)
'                  It never reads batch/result files to decide what exists, so it does not matter which machine
'                  or which release (4.5 or older) registered a user.
' Uses           : BulkRegAgents (and through it BulkRegCommon). Nothing in those libraries is changed by this one:
'                  agents 00-12 keep running as before.
' Runs in        : HCL Domino Administrator client on WINDOWS only (like every BulkReg agent)
'
' HOW TO INSTALL : Designer > Code > Script Libraries > New LotusScript Library, name it exactly "BulkRegRecover".
'                  Ctrl+A, Delete, paste this WHOLE file, Ctrl+S. Create the one-line agent from Agent13_Recover.lss.
'                  Not compiled or run against Domino.
'
' Mail files on the servers: the agent reads the CSV lists written on each mail server by
'   scripts/linux/bulkreg_list_mailfiles.sh  or  scripts/windows/BulkReg_ListMailFiles.ps1
' and copied to MailListDir (default <BaseDir>\maillists\). Columns: Server,Path,Bytes,Modified. A list is much faster
' than opening every file, and the size shows cut-off files (smaller than RecoverShellMaxBytes) without opening the
' large ones. A server without a list is checked live (slower). Existence is ALWAYS confirmed with one live open
' before a file is created, so a stale list can never cause an overwrite.
'
' States (RECOVER_<run>_plan.csv, Include=Y = fixed by this agent):
'   MAIL_MISSING -> CREATE_MAIL      EMPTY_SHELL -> REPLACE_SHELL (RepairRemoveEmptyShells=1, BulkReg mail folder only)
'   DUPLICATE -> REMOVE_DUPLICATE    BLOCKED_STALE_BATCH -> CLOSE_BATCH
'   READY_FOR_02 -> REGISTER (02 + 03)   ACL_TITLE_OFF -> FIX_ACL_TITLE   REPLICAS_MISSING -> REQUEST_REPLICAS
'   everything else -> MANUAL with the reason in Detail
' Several machines: PartitionCount / PartitionIndex (4.5.0) + a guard in the central log database (RecoverGuard=1).
' Idempotent: the plan is rebuilt from the directory each run; after a stop, hang or crash simply run it again.
'=====================================================================
'#####################################################################
' --- part 1: (Options) ---
'#####################################################################
Option Public
Option Declare
Use "BulkRegAgents"
'#####################################################################
' --- part 2: (Declarations) ---
'#####################################################################
Dim gRecSecExists As Double      ' seconds of the last create: existence check
Dim gRecSecCreate As Double      ' seconds of the last create: CreateFromTemplate (+ title)
Dim gRecSecAcl As Double         ' seconds of the last create: ACL
Dim gRecDb As NotesDatabase      ' the directory
Dim gRecInv List As String       ' mail files per server (from the CSV lists, else a live listing)
Dim gRecSizes List As Double     ' bytes per mail file (CSV lists only)
Dim gRecSrvOk List As String     ' server reachability cache
Dim gRecOpenIds List As String   ' NoteID -> batch file of this machine's open / stopped batches
Dim gRecBatchOf List As String   ' for BR_DupEval
Dim gRecBatchAge List As String  ' batch file -> "STALE" / "FRESH"
Dim gRecBatchUsers List As Long  ' batch file -> number of unregistered users it holds back
Dim gRecDupMethod As String
Dim gRecDupMust As String
Dim gRecReqFile As String
Dim gRecStaleHours As Long
Dim gRecShellMax As Double
Dim gRecTrustSize As Boolean
Dim gRecCheckLevel As Long
Dim gRecCheckRep As Boolean

'#####################################################################
' --- part 3: Subs and Functions (Designer gives each its own entry) ---
'#####################################################################
Sub BR_RunRecover()
    On Error GoTo ErrH
    Dim ws As NotesUIWorkspace, ans As Variant
    Dim col As NotesDocumentCollection, doc As NotesDocument
    Dim cnt List As Long, openNames List As String, openCounts List As Long
    Dim wNid() As String, wAct() As String, wKeep() As String, nW As Long, capW As Long
    Dim createdNid() As String, nCreated As Long, capC As Long
    Dim nScanned As Long, nOther As Long, listInfo As String
    Dim st As String, act As String, detail As String, keeper As String, inc As String, rowTxt As String, bfile As String
    Dim origReplicas As Boolean, overlap As String
    Dim planFile As String, timeFile As String, fhPlan As Integer, seq As Long, outDir As String, snapDir As String
    Dim i As Long, pass As Long, nMade As Long, nFix As Long, nExist As Long, nSkip As Long, nFail As Long, nConsec As Long, nSlowRow As Long, nSlowTotal As Long
    Dim nDup As Long, nDupBad As Long, nBatchClosed As Long
    Dim chunk As Long, basePause As Long, pauseSec As Long, pauseMs As Long, maxConsec As Long, maxMin As Long
    Dim slowSec As Long, maxSlow As Long, maxPer As Long, maxDel As Long, workDone As Long, lastMark As Long
    Dim tChunk As Double, tRun As Double, tItem As Double
    Dim res As String, stopReason As String, summary As String, countText As String
    Dim nActionable As Long, nManual As Long, nReady As Long, nDupPlan As Long, nBatchPlan As Long
    Dim nid As String, unid As String, why As String, via As String, delName As String, reqId As String, snapErr As String
    Dim nVerOk As Long, nVerBad As Long, nRepReq As Long, nRepBad As Long
    Dim dDoc As NotesDocument, bk As String, skipThis As Boolean

    gMode = "": gStopRun = ""
    Set gTmplDb = Nothing: gTmplKey = ""
    If Not BR_Init("Recover") Then Exit Sub
    If CfgB("DryRun", True) Then gMode = "DRYRUN" Else gMode = "LIVE"
    maxConsec = CfgL("MaxConsecutiveErrors", 5)
    pauseMs = CfgL("PauseMs", 500)
    maxPer = CfgL("RecoverMaxCreates", 250)            ' mail files per session; then close Notes and run again (0 = no limit)
    maxDel = CfgL("DuplicateMaxDelete", 25)            ' 0 = no limit (duplicates, same key as agent 12)
    chunk = CfgL("MailRepairChunkSize", 10)
    basePause = CfgL("ChunkPauseSec", 5)
    If basePause < 0 Then basePause = 0
    pauseSec = basePause
    gRecCheckLevel = CfgL("RecoverCheckExisting", 1)   ' 0 = exists only | 1 = + completeness | 2 = + title and ACL
    gRecCheckRep = CfgB("RecoverCheckReplicas", False)
    maxMin = CfgL("RecoverMaxMinutes", 60)
    slowSec = CfgL("RecoverSlowCreateSec", 60)
    maxSlow = CfgL("RecoverMaxSlowInRow", 3)
    gRecStaleHours = CfgL("RecoverStaleBatchHours", 24)
    gRecShellMax = CDbl(CfgL("RecoverShellMaxBytes", 1048576))
    gRecTrustSize = CfgB("RecoverTrustSize", True)
    gRecDupMethod = UCase$(Trim$(CfgS("DuplicateDeleteMethod", "ADMINP")))
    If gRecDupMethod <> "ADMINP" And gRecDupMethod <> "DIRECT" And gRecDupMethod <> "AUTO" Then Error 8104, "DuplicateDeleteMethod must be ADMINP, DIRECT or AUTO (found: " & gRecDupMethod & ")"
    gRecDupMust = "," & LCase$(Replace(Trim$(CfgS("DuplicateMustMatch", "name,short,inet,first,last")), " ", "")) & ","
    origReplicas = CfgB("CreateClusterReplicas", True)
    Erase gRecInv: Erase gRecSizes: Erase gRecSrvOk: Erase gRecOpenIds: Erase gRecBatchOf: Erase gRecBatchAge: Erase gRecBatchUsers

    If Trim$(CfgS("MailTemplate", "")) = "" Then
        BR_Close "MailTemplate missing"
        BR_Msg "MailTemplate (e.g. mail145.ntf) is required in bulkreg.ini to create mail files.", 16
        Exit Sub
    End If
    If Dir$(BR_StopFile()) <> "" Then
        BR_Close "STOP.txt present"
        BR_Msg "STOP.txt exists in " & BR_BatchDir() & ". Delete it to run again.", 48
        Exit Sub
    End If

    ' ---------- several machines: record this run's partition, refuse an overlapping run ----------
    Call BRR_RecordPartition()
    If CfgB("RecoverGuard", True) Then
        overlap = BRR_OtherRunsActive()
        If overlap <> "" Then
            Set ws = New NotesUIWorkspace
            If CInt(ws.Prompt(PROMPT_YESNO, "BulkReg - Recover Users", "Another Recover run is RUNNING in the log database with an overlapping partition:" & Chr$(10) & Chr$(10) & overlap & Chr$(10) & _
            "Two runs on the same users can create a mail file twice. This machine: " & BR_PartitionText() & Chr$(10) & Chr$(10) & _
            "Only continue if that run has ended (crashed client, closed window). Continue anyway?")) <> 1 Then
                BR_Close "Cancelled: overlapping run"
                Exit Sub
            End If
            BR_Log LVL_WARN, "Overlapping Recover run ignored by the operator: " & Replace(overlap, Chr$(10), " | ")
        End If
    End If

    planFile = BR_BatchDir() & "RECOVER_" & gRunID & "_plan.csv"
    timeFile = BR_BatchDir() & "RECOVER_" & gRunID & "_timing.csv"
    gResultsFile = BR_BatchDir() & "RECOVER_" & gRunID & "_results.csv"
    Call BR_AppendLine(gResultsFile, Uchr$(&HFEFF) & BR_AuditHeader())
    Call BR_AppendLine(timeFile, Uchr$(&HFEFF) & "Seq,Timestamp,Server,MailFile,Action,Result,SecExists,SecCreate,SecAcl,SecTotal")
    fhPlan = BR_CsvOpen(planFile, "Include,Seq,State,Action,MailServer,MailFile,FullName,ShortName,NoteID,UNID,Partition,Detail")

    ' ---------- 1. SCAN (read only) ----------
    Set gRecDb = BR_OpenDirectory()
    BR_Log LVL_INFO, "Directory: " & gRecDb.Server & "!!" & gRecDb.FilePath & " | last modified " & Format$(gRecDb.LastModified, "yyyy-mm-dd hh:nn:ss") & " | " & BR_PartitionText()
    listInfo = BRR_LoadMailLists()
    BR_Log LVL_INFO, "Mail file lists: " & BR_IIfStr(listInfo = "", "none found in " & BR_CfgDir("MailListDir", "maillists") & " - the servers are checked live (slower)", listInfo)
    Call BR_OpenBatchNoteIDs(gRecOpenIds, openNames, openCounts)
    Call BR_ReconBatchMap(gRecBatchOf)
    Call BR_DupIndexLoad(gRecDb)
    outDir = BR_CfgDir("ReconcileDir", "reconcile")
    On Error Resume Next
    MkDir Left$(outDir, Len(outDir) - 1)
    Err = 0
    On Error GoTo ErrH
    If Not BR_DirWritable(outDir) Then outDir = gRunDir
    gRecReqFile = outDir & "DEDUP_requested.txt"

    Set col = BR_GetCandidates(gRecDb, False)
    Set doc = col.GetFirstDocument()
    Do While Not (doc Is Nothing)
        nScanned = nScanned + 1
        nid = CStr(doc.NoteID): unid = CStr(doc.UniversalID)
        If BR_NotMyPartition(unid) Then
            nOther = nOther + 1
        Else
            st = BRR_Classify(doc, act, detail, keeper, bfile)
            If st <> "" Then
                If IsElement(cnt(st)) Then cnt(st) = cnt(st) + 1 Else cnt(st) = 1
                If st <> "MAIL_OK" Then
                    seq = seq + 1
                    inc = "N"
                    Select Case act
                    Case "CREATE_MAIL", "REPLACE_SHELL", "FIX_ACL_TITLE", "REQUEST_REPLICAS", "REMOVE_DUPLICATE"
                        inc = "Y"
                        If nW >= capW Then
                            capW = capW + 500
                            ReDim Preserve wNid(capW) As String, wAct(capW) As String, wKeep(capW) As String
                        End If
                        wNid(nW) = nid: wAct(nW) = act: wKeep(nW) = keeper
                        nW = nW + 1
                        If act = "REMOVE_DUPLICATE" Then nDupPlan = nDupPlan + 1
                    Case "CLOSE_BATCH"
                        inc = "Y"
                    Case "REGISTER"
                        nReady = nReady + 1
                    Case "MANUAL"
                        nManual = nManual + 1
                    End Select
                    rowTxt = Q(inc) & "," & seq & "," & Q(st) & "," & Q(act) & "," & Q(BR_SrvAbbr(BR_Item(doc, "MailServer"))) & "," & Q(BR_MailPathNorm(BR_Item(doc, "MailFile"))) & "," & _
                    Q(BR_Item(doc, "FullName")) & "," & Q(BR_PickShortName(doc)) & "," & Q(nid) & "," & Q(unid) & "," & BR_PartitionOf(unid) & "," & Q(detail)
                    Print #fhPlan, rowTxt
                End If
            End If
        End If
        If nScanned Mod 250 = 0 Then Print "BulkReg RECOVER scan: " & nScanned & "/" & col.Count & "  to do=" & nW & " manual=" & nManual
        Set doc = col.GetNextDocument(doc)
    Loop
    Close #fhPlan
    ForAll bs In gRecBatchAge
        If bs = "STALE" Then nBatchPlan = nBatchPlan + 1
    End ForAll
    nActionable = nW + nBatchPlan
    ForAll c In cnt
        countText = countText & "  " & ListTag(c) & ": " & c & Chr$(10)
    End ForAll
    BR_Log LVL_INFO, "Scan: scanned " & nScanned & " | other machine's users (not touched) " & nOther & " | to do " & nW & " | stale batches to close " & nBatchPlan & " | manual " & nManual & " | ready for 02 " & nReady & " | " & Replace(countText, Chr$(10), " ")
    countText = "Directory users scanned: " & nScanned & Chr$(10) & "Other machine's users (untouched): " & nOther & Chr$(10) & countText & Chr$(10) & _
    "Fixed by this agent: " & nW & " users" & BR_IIfStr(nDupPlan > 0, " (" & nDupPlan & " duplicates to remove)", "") & Chr$(10) & _
    "Stale batch files to close (they hide users from 02): " & nBatchPlan & Chr$(10) & _
    "Needs a person (MANUAL): " & nManual & Chr$(10) & "Ready for 02 + 03 (not registered yet): " & nReady & Chr$(10) & "Plan: " & planFile

    If nActionable = 0 Then
        summary = gMode & " | scanned=" & nScanned & " | nothing for this agent to do | ready for 02=" & nReady & " manual=" & nManual & " | " & BR_PartitionText()
        BR_Close summary
        BR_Msg "NOTHING TO DO for this agent." & Chr$(10) & Chr$(10) & countText & BR_IIfStr(nReady > 0, Chr$(10) & "NEXT: run 02 - Build Batch, review, then 03 - Register Batch.", ""), 64
        Exit Sub
    End If

    ' ---------- confirmation ----------
    If gMode = "DRYRUN" Then
        summary = "DRYRUN | scanned=" & nScanned & " to do=" & nW & " stale batches=" & nBatchPlan & " manual=" & nManual & " ready for 02=" & nReady & " | " & BR_PartitionText()
        BR_Close summary
        BR_Msg "DRY RUN (DryRun=1): nothing was removed, created or closed." & Chr$(10) & Chr$(10) & countText & Chr$(10) & "Read the plan, then set DryRun=0 and run again.", 64
        Exit Sub
    End If
    Set ws = New NotesUIWorkspace
    ans = ws.Prompt(PROMPT_OKCANCELEDIT, "BulkReg - Recover Users (LIVE)", _
    "LIVE (" & BR_PartitionText() & "):" & Chr$(10) & countText & Chr$(10) & _
    "In this order: remove duplicates (max " & BR_IIfStr(maxDel > 0, CStr(maxDel), "unlimited") & ", snapshot first, mail files and keepers untouched), create mail files from " & CfgS("MailTemplate", "") & ", close stale batches, verify, request cluster replicas." & Chr$(10) & _
    "Limits: " & BR_IIfStr(maxMin > 0, maxMin & " min", "no time limit") & ", stops when the server is slow. Create " & BR_StopFile() & " to stop cleanly; run again to continue." & Chr$(10) & Chr$(10) & "Type RECOVER to approve:", "")
    If IsEmpty(ans) Then ans = ""
    If CStr(ans) <> "RECOVER" Then
        BR_Log LVL_WARN, "LIVE recover not approved - aborted"
        BR_Close "Not approved"
        Exit Sub
    End If
    If nDupPlan > 0 Then
        snapDir = BR_CfgDir("PasswordDir", "secure") & "DEDUP_" & gRunID & gSep
        On Error Resume Next
        MkDir Left$(snapDir, Len(snapDir) - 1)
        Err = 0
        On Error GoTo ErrH
        If Not BR_DirWritable(snapDir) Then Error 8105, "Snapshot folder is not writable (PasswordDir): " & snapDir
    End If

    ' ---------- 2. ACT. Pass 1 = duplicates, pass 2 = mail files. Replicas are requested in step 3 ----------
    gCfg("createclusterreplicas") = "0"
    tChunk = Timer
    tRun = Timer
    For pass = 1 To 2
        For i = 0 To nW - 1
            skipThis = ((wAct(i) = "REMOVE_DUPLICATE") <> (pass = 1))
            If Not skipThis Then
                tItem = Timer
                Set doc = Nothing
                On Error Resume Next
                Set doc = gRecDb.GetDocumentByID(wNid(i))
                Err = 0
                On Error GoTo ErrH
                gRecSecExists = 0: gRecSecCreate = 0: gRecSecAcl = 0
                Select Case wAct(i)
                Case "REMOVE_DUPLICATE"
                    If maxDel > 0 And nDup >= maxDel Then
                        res = "SKIP:cap"
                        BR_Log LVL_INFO, "DuplicateMaxDelete (" & maxDel & ") reached - run again for the rest"
                    Else
                        res = BRR_RemoveDuplicate(wNid(i), wKeep(i), snapDir)
                        If Left$(res, 2) = "OK" Then
                            nDup = nDup + 1
                        ElseIf Left$(res, 2) = "FA" Then
                            nDupBad = nDupBad + 1
                        End If
                        If pauseMs > 0 And Left$(res, 2) = "OK" Then Sleep pauseMs / 1000
                    End If
                Case "CREATE_MAIL"
                    res = BRR_CreateOne(doc, wNid(i))
                Case "REPLACE_SHELL"
                    res = BR_RepairOne(doc, wNid(i), "K", 1)
                Case "FIX_ACL_TITLE"
                    res = BR_RepairOne(doc, wNid(i), "K", 2)
                Case "REQUEST_REPLICAS"
                    res = BRR_ReplicasOne(doc, wNid(i))
                Case Else
                    res = "SKIP:action"
                End Select
                Select Case Left$(res, 2)
                Case "OK"
                    nConsec = 0
                    If wAct(i) <> "REMOVE_DUPLICATE" Then
                        nMade = nMade + 1
                        If wAct(i) <> "REQUEST_REPLICAS" Then
                            If nCreated >= capC Then
                                capC = capC + 500
                                ReDim Preserve createdNid(capC) As String
                            End If
                            createdNid(nCreated) = wNid(i)
                            nCreated = nCreated + 1
                        End If
                    End If
                Case "EX": nExist = nExist + 1: nConsec = 0
                Case "FX": nFix = nFix + 1: nConsec = 0
                Case "SK": nSkip = nSkip + 1
                Case Else: nFail = nFail + 1: nConsec = nConsec + 1
                End Select
                If wAct(i) <> "REMOVE_DUPLICATE" Then
                    Call BR_AppendLine(timeFile, i + 1 & "," & Q(Format$(Now, "yyyy-mm-dd hh:nn:ss")) & "," & Q(BRR_SrvOf(doc)) & "," & Q(BRR_MailOf(doc)) & "," & Q(wAct(i)) & "," & Q(res) & "," & _
                    Format$(gRecSecExists, "0.0") & "," & Format$(gRecSecCreate, "0.0") & "," & Format$(gRecSecAcl, "0.0") & "," & Format$(BR_Elapsed(tItem), "0.0"))
                End If
                Print "BulkReg RECOVER: " & (i + 1) & "/" & nW & "  duplicates removed=" & nDup & " mail created/replaced=" & nMade & " fixed=" & nFix & " fail=" & nFail & " skip=" & nSkip
                Set doc = Nothing

                ' slowness: a create that takes very long is the sign of a server in trouble - stop instead of piling up
                If wAct(i) = "CREATE_MAIL" And Left$(res, 2) = "OK" Then
                    If slowSec > 0 And gRecSecCreate > slowSec Then
                        nSlowRow = nSlowRow + 1: nSlowTotal = nSlowTotal + 1
                        BR_Log LVL_WARN, "Slow create: " & Format$(gRecSecCreate, "0.0") & " s (limit " & slowSec & " s), " & nSlowRow & " in a row"
                    Else
                        nSlowRow = 0
                    End If
                    If maxSlow > 0 And nSlowRow >= maxSlow Then
                        stopReason = "SLOW: " & nSlowRow & " creates in a row took more than " & slowSec & " s. The server is struggling: wait, then run again"
                        BR_Log LVL_ERROR, stopReason
                        Exit For
                    End If
                End If
                If nConsec >= maxConsec Then
                    stopReason = "Circuit breaker: " & nConsec & " consecutive failures"
                    BR_Log LVL_ERROR, stopReason
                    Exit For
                End If
                If wAct(i) <> "REMOVE_DUPLICATE" And maxPer > 0 And nMade >= maxPer Then
                    stopReason = "RecoverMaxCreates (" & maxPer & ") reached - run again for the rest"
                    BR_Log LVL_INFO, stopReason
                    Exit For
                End If
                If maxMin > 0 And BR_Elapsed(tRun) > maxMin * 60 Then
                    stopReason = "RecoverMaxMinutes (" & maxMin & ") reached - run again, it continues where it stopped"
                    BR_Log LVL_INFO, stopReason
                    Exit For
                End If
                If wAct(i) <> "REMOVE_DUPLICATE" Then
                    If pauseMs > 0 And Left$(res, 2) = "OK" Then Sleep pauseMs / 1000
                    workDone = nMade + nFix
                    If chunk > 0 And (workDone - lastMark) >= chunk Then
                        lastMark = workDone
                        stopReason = BR_ChunkEnd("Recover", i + 1, nW, chunk, tChunk, pauseSec, basePause, nMade, nFail)
                        If stopReason <> "" Then
                            BR_Log LVL_WARN, stopReason
                            Exit For
                        End If
                        Set gRecDb = BR_OpenDirectory()           ' fresh handle per chunk (like 03 and 08)
                    End If
                End If
            End If
        Next
        If stopReason <> "" Then Exit For
    Next
    gCfg("createclusterreplicas") = BR_IIfStr(origReplicas, "1", "0")

    ' ---------- close stale batch files (only when the run was not stopped early) ----------
    If stopReason = "" Then
        ForAll bt In gRecBatchAge
            If bt = "STALE" Then
                bk = ListTag(bt)
                If BRR_CloseBatch(bk) Then nBatchClosed = nBatchClosed + 1
            End If
        End ForAll
    End If

    ' ---------- 3. FINISH: verify what was created, then request the cluster replicas ----------
    Set gRecDb = BR_OpenDirectory()
    If nCreated > 0 Then Call BRR_FinishCreated(gRecDb, createdNid, nCreated, origReplicas, nVerOk, nVerBad, nRepReq, nRepBad)

    If stopReason = "" Then stopReason = "All planned work processed"
    Set gTmplDb = Nothing
    summary = gMode & " | duplicates removed=" & nDup & " failed=" & nDupBad & " | mail created/replaced=" & nMade & " existing=" & nExist & " fixed=" & nFix & " skipped=" & nSkip & " failed=" & nFail & " slow=" & nSlowTotal & _
    " | verified OK=" & nVerOk & " bad=" & nVerBad & " | replicas requested=" & nRepReq & " failed=" & nRepBad & " | stale batches closed=" & nBatchClosed & " | ready for 02=" & nReady & " manual=" & nManual & " | " & stopReason
    BR_Close summary
    BR_Msg summary & Chr$(10) & Chr$(10) & "Results: " & gResultsFile & Chr$(10) & "Timing: " & timeFile & Chr$(10) & "Log: " & gDebugFile & Chr$(10) & Chr$(10) & _
    BR_IIfStr(nFail > 0 Or nVerBad > 0 Or nDupBad > 0 Or stopReason <> "All planned work processed", "NOT COMPLETE. Run the agent again (DryRun=1 first) until it reports 'nothing for this agent to do'.", "Planned work finished. Run the agent once more with DryRun=1: it must report 'nothing for this agent to do'.") & Chr$(10) & _
    BR_IIfStr(nReady + nBatchClosed > 0, "NEXT: run 02 - Build Batch (it now finds the remaining users), review, then 03 - Register Batch." & Chr$(10), "") & _
    BR_IIfStr(InStr(stopReason, "reached") > 0 Or Left$(stopReason, 4) = "SLOW", "SESSION LIMIT: close Notes completely, open it again, then run the agent again (this releases every client handle)." & Chr$(10), "") & _
    "AdminP creates the replicas and removes duplicates over the next minutes/hours.", CInt(BR_IIfStr(nFail > 0 Or nVerBad > 0 Or nDupBad > 0, "48", "64"))
    Exit Sub

ErrH:
    On Error Resume Next
    Close #fhPlan
    gCfg("createclusterreplicas") = BR_IIfStr(origReplicas, "1", "0")
    Set gTmplDb = Nothing
    BR_Log LVL_ERROR, "Recover aborted: " & Error$ & " (err " & Err & ", line " & Erl & ")"
    BR_Close "ABORTED"
    BR_Msg "Recover aborted: " & Error$ & Chr$(10) & "Nothing is lost: the plan is rebuilt from the directory, run the agent again." & Chr$(10) & "See " & gDebugFile, 16
    Exit Sub
End Sub

' ---------------------------------------------------------------------
' Classify ONE Person document. Returns the state ("" = out of scope), act = the action, detail = why,
' keeper = NoteID of the registered keeper (duplicates), bfile = batch file that holds the user back.
' Read only. Uses the module globals set by BR_RunRecover (directory, inventory, open batches, settings).
' ---------------------------------------------------------------------
Function BRR_Classify(doc As NotesDocument, act As String, detail As String, keeper As String, bfile As String) As String
    On Error GoTo ErrH
    Dim srv As String, mf As String, present As Boolean, health As String, folder As String, rr As String, key As String
    Dim u As BRUser, aRes As String, tRes As String, repl As String, dupTxt As String, p As Long, ev As String, why As String, via As String, delName As String
    Dim nid As String, ageState As String
    act = "": detail = "": keeper = "": bfile = ""
    nid = CStr(doc.NoteID)

    ' ---------- not registered ----------
    If Not BR_IsRegistered(doc) Then
        Call BR_ReadUser(doc, u)
        dupTxt = BR_DupCheck(u)
        If dupTxt <> "" Then
            If InStr(dupTxt, "DUPLICATE_REGISTERED") > 0 Then
                p = InStr(dupTxt, "NoteID ")
                If p > 0 Then keeper = StrLeft(Mid$(dupTxt, p + 7), " ")
                ev = BR_DupEval(gRecDb, nid, keeper, gRecDupMethod, gRecDupMust, gRecBatchOf, gRecReqFile, why, via, delName)
                If ev = "OK" Then
                    BRR_Classify = "DUPLICATE": act = "REMOVE_DUPLICATE"
                    detail = "Unregistered full duplicate of the registered NoteID " & keeper & ": removed via " & via
                ElseIf ev = "GONE" Then
                    BRR_Classify = "": keeper = ""
                Else
                    BRR_Classify = "DUPLICATE_REVIEW": act = "MANUAL": keeper = ""
                    detail = ev & ": " & why
                End If
            Else
                BRR_Classify = "DUPLICATE_OTHER": act = "MANUAL"
                detail = Left$(dupTxt, 250)
            End If
            Exit Function
        End If
        If IsElement(gRecOpenIds(nid)) Then
            bfile = CStr(gRecOpenIds(nid))
            ageState = BRR_BatchAgeState(bfile)
            If ageState = "STALE" Then
                BRR_Classify = "BLOCKED_STALE_BATCH": act = "CLOSE_BATCH"
                detail = bfile & " is open or stopped for more than " & gRecStaleHours & " h and holds this user back from 02: it is closed, then 02 builds the user"
            Else
                BRR_Classify = "BLOCKED_RECENT_BATCH": act = "MANUAL"
                detail = bfile & " is a recent open batch: run 03 on it, or close it with 11 - Batch Manager (CLOSE), then 02 builds the user"
            End If
            Exit Function
        End If
        If u.InternetAddress = "" And CfgB("SkipNoInternetAddress", True) Then
            BRR_Classify = "NO_INTERNET_ADDRESS": act = "MANUAL"
            detail = "02 skips users without an Internet address: add it in AD (DirSync), or set InternetDomain so it can be constructed"
            Exit Function
        End If
        BRR_Classify = "READY_FOR_02": act = "REGISTER"
        detail = "Nothing holds this user back: 02 - Build Batch includes the user, then 03 registers"
        If CfgS("BatchServerFilter", "") <> "" Then detail = detail & " (BatchServerFilter=" & CfgS("BatchServerFilter", "") & " may hide users of other servers from 02)"
        Exit Function
    End If

    ' ---------- registered: mail item ----------
    srv = BR_SrvAbbr(BR_Item(doc, "MailServer"))
    mf = BR_MailPathNorm(BR_Item(doc, "MailFile"))
    If srv = "" Or mf = "" Then
        BRR_Classify = "NO_MAIL_ITEM": act = "MANUAL"
        detail = "Registered, but the Person document has no MailServer/MailFile: set both items, then run again"
        Exit Function
    End If
    If Not BR_HomeServerOK(srv, gRecSrvOk) Then
        BRR_Classify = "SERVER_UNREACHABLE": act = "MANUAL"
        detail = srv & " does not answer: nothing is planned for its users. Fix the server, then run again"
        Exit Function
    End If

    ' does the file exist? (CSV list or one directory listing per server; a file missing there is confirmed with one open)
    Call BR_MailInventory(srv, gRecInv)
    If BR_InvLoaded(srv, gRecInv) Then
        present = BR_InvHas(srv, mf, gRecInv)
        If Not present Then present = BR_MailFileExists(srv, mf)
    Else
        present = BR_MailFileExists(srv, mf)
    End If
    If Not present Then
        BRR_Classify = "MAIL_MISSING": act = "CREATE_MAIL"
        detail = "Mail file " & srv & "!!" & mf & " does not exist"
        Exit Function
    End If

    ' exists: complete? A large file from a CSV list is trusted (a cut-off create leaves a tiny file); a small one is opened
    If gRecCheckLevel >= 1 Then
        key = LCase$(BR_SrvAbbr(srv)) & "!!" & LCase$(BR_Path(mf))
        If gRecTrustSize And IsElement(gRecSizes(key)) Then
            If gRecSizes(key) >= gRecShellMax Then health = "OK" Else health = BR_MailHealth(srv, mf)
        Else
            health = BR_MailHealth(srv, mf)
        End If
        If health <> "OK" Then
            If Left$(health, 9) = "NO_DESIGN" Then
                folder = ""
                If InStr(mf, "\") > 0 Then folder = StrLeftBack(mf, "\")
                If InStr(health, "EMPTY") > 0 Then
                    BRR_Classify = "EMPTY_SHELL"
                    If CfgB("RepairRemoveEmptyShells", False) And BR_IsNewMailFolder(folder) Then
                        act = "REPLACE_SHELL"
                        detail = "File exists without design and without documents (a create that was cut off): removed and recreated"
                    Else
                        act = "MANUAL"
                        detail = "Empty shell: remove it on the server, or set RepairRemoveEmptyShells=1 (only in a BulkReg numbered mail folder)"
                    End If
                Else
                    BRR_Classify = "NO_DESIGN_HAS_DATA": act = "MANUAL"
                    detail = "No design but " & health & ": never recreated. Replace the design from " & CfgS("MailTemplate", "") & " in Domino Administrator"
                End If
            Else
                BRR_Classify = "CHECK_ERROR": act = "MANUAL"
                detail = "Completeness check failed: " & health
            End If
            Exit Function
        End If
    End If
    If gRecCheckLevel >= 2 Then
        Call BR_LightUser(doc, u)
        aRes = BR_MailAclFix(srv, mf, u.FullNameAfter, False)
        tRes = BR_MailTitleFix(srv, mf, BR_MailTitle(u), False, CfgB("MailFileTitleOverwrite", False))
        If InStr(aRes, "ACL_MISSING") > 0 Or tRes = "TITLE_EMPTY" Then
            BRR_Classify = "ACL_TITLE_OFF": act = "FIX_ACL_TITLE"
            detail = aRes & "; " & tRes
            Exit Function
        End If
    End If
    If gRecCheckRep Then
        repl = BR_ReplicaServers(srv, "")
        If repl <> "" Then
            rr = BR_CheckReplicas(srv, mf, repl)
            If Left$(rr, 16) = "REPLICAS_MISSING" Then
                BRR_Classify = "REPLICAS_MISSING": act = "REQUEST_REPLICAS"
                detail = rr
                Exit Function
            End If
        End If
    End If
    BRR_Classify = "MAIL_OK"
    Exit Function
ErrH:
    BRR_Classify = "CHECK_ERROR": act = "MANUAL"
    detail = "err " & Err & ": " & Error$
    Exit Function
End Function

' "STALE" / "FRESH" for a batch file that is OPEN or STOPPED on this machine (cached; counts the users it holds back).
' STALE = the batch file (or its in-progress flag) was last written more than RecoverStaleBatchHours ago.
Function BRR_BatchAgeState(bfile As String) As String
    On Error GoTo ErrH
    Dim bid As String, f As String, ageH As Double, st As String
    If IsElement(gRecBatchAge(bfile)) Then
        If IsElement(gRecBatchUsers(bfile)) Then gRecBatchUsers(bfile) = gRecBatchUsers(bfile) + 1 Else gRecBatchUsers(bfile) = 1
        BRR_BatchAgeState = gRecBatchAge(bfile)
        Exit Function
    End If
    bid = Left$(bfile, Len(bfile) - 4)
    f = BR_BatchDir() & bfile
    If Dir$(BR_BatchFlagFile(bid)) <> "" Then f = BR_BatchFlagFile(bid)
    ageH = (Now - FileDateTime(f)) * 24
    If gRecStaleHours > 0 And ageH > gRecStaleHours Then st = "STALE" Else st = "FRESH"
    gRecBatchAge(bfile) = st
    gRecBatchUsers(bfile) = 1
    BR_Log LVL_INFO, "Batch " & bfile & " holds users back from 02: " & st & " (" & Format$(ageH, "0.0") & " h old)"
    BRR_BatchAgeState = st
    Exit Function
ErrH:
    gRecBatchAge(bfile) = "FRESH"
    BRR_BatchAgeState = "FRESH"
    Exit Function
End Function

' Closes a stale OPEN or STOPPED batch file like 11 - Batch Manager CLOSE (STOPPED: flag removed; OPEN: header-only results file).
' Users already registered stay registered; the others become eligible for 02. Returns True when closed.
Function BRR_CloseBatch(bfile As String) As Boolean
    On Error GoTo ErrH
    Dim bid As String, flagF As String, resF As String
    bid = Left$(bfile, Len(bfile) - 4)
    flagF = BR_BatchFlagFile(bid)
    resF = BR_BatchDir() & bid & "_results.csv"
    If Dir$(flagF) <> "" Then
        Kill flagF
    ElseIf Dir$(resF) = "" Then
        Call BR_AppendLine(resF, Uchr$(&HFEFF) & BR_AuditHeader())
    Else
        Exit Function
    End If
    BR_Log LVL_WARN, "CLOSE (stale batch): " & bid & " closed by Recover " & gRunID & " (" & BR_ListLongText(gRecBatchUsers, bfile) & " unregistered users were held back)"
    BRR_CloseBatch = True
    Exit Function
ErrH:
    BR_Log LVL_ERROR, "Could not close batch " & bfile & ": " & Error$
    Exit Function
End Function

' ---------------------------------------------------------------------
' REMOVE_DUPLICATE: same checks and removal as agent 12 (BR_DupEval, snapshot, BR_DupRemove), live re-check first.
' Returns OK / SKIP:... / FAIL:... Mail files, ID files and the keeper are never touched.
' ---------------------------------------------------------------------
Function BRR_RemoveDuplicate(nid As String, keeper As String, snapDir As String) As String
    On Error GoTo ErrH
    Dim why As String, via As String, delName As String, res As String, d As NotesDocument, snapErr As String, reqId As String, t0 As Double
    t0 = Timer
    res = BR_DupEval(gRecDb, nid, keeper, gRecDupMethod, gRecDupMust, gRecBatchOf, gRecReqFile, why, via, delName)
    If res <> "OK" Then
        Call BR_DupAuditRow(gRecDb, nid, "RECOVER", keeper, res, why, Timer - t0)
        BRR_RemoveDuplicate = "SKIP:" & res
        Exit Function
    End If
    Set d = gRecDb.GetDocumentByID(nid)
    snapErr = BR_DupSnapshot(d, snapDir, nid)
    If snapErr <> "" Then
        Call BR_DupAuditRow(gRecDb, nid, "RECOVER", keeper, "FAILED_SNAPSHOT", "no snapshot, nothing removed: " & snapErr, Timer - t0)
        BRR_RemoveDuplicate = "FAIL:snapshot"
        Exit Function
    End If
    res = BR_DupRemove(gRecDb, d, nid, via, delName, gRecReqFile, reqId, why)
    Call BR_DupAuditRow(gRecDb, nid, "RECOVER", keeper, res, why, Timer - t0)
    If Left$(res, 6) = "FAILED" Then BRR_RemoveDuplicate = "FAIL:remove" Else BRR_RemoveDuplicate = "OK"
    Exit Function
ErrH:
    BR_Log LVL_ERROR, "Remove duplicate " & nid & " failed: " & Error$ & " (line " & Erl & ")"
    BRR_RemoveDuplicate = "FAIL:error"
    Exit Function
End Function

' ---------------------------------------------------------------------
' Mail file lists written on the mail servers (Server,Path,Bytes,Modified) from MailListDir.
' Fills gRecInv (same keys as BR_MailInventory) and gRecSizes. Returns a description, "" = no list found.
' ---------------------------------------------------------------------
Function BRR_LoadMailLists() As String
    On Error GoTo ErrH
    Dim dirPath As String, f As String, files List As String, fh As Integer, txt As String, cols List As Integer, delim As String, parts As Variant
    Dim isFirst As Boolean, sk As String, pth As String, nRows As Long, perSrv List As Long, info As String, ageH As Double, bytes As String
    dirPath = BR_CfgDir("MailListDir", "maillists")
    f = Dir$(dirPath & "*.csv")
    Do While f <> ""
        files(f) = f
        f = Dir$()
    Loop
    ForAll lf In files
        fh = FreeFile()
        Open dirPath & lf For Input As #fh Charset = "UTF-8"
        isFirst = True
        Do Until EOF(fh)
            Line Input #fh, txt
            txt = Replace(txt, Uchr$(&HFEFF), "")
            If isFirst Then
                Call BR_CsvHeader(txt, delim, cols)
                isFirst = False
                If Not IsElement(cols("server")) Or Not IsElement(cols("path")) Then
                    BR_Log LVL_WARN, "Mail list " & lf & " skipped: columns Server and Path are required"
                    Exit Do
                End If
            ElseIf Trim$(txt) <> "" Then
                parts = BR_CsvSplit(txt, delim)
                sk = LCase$(BR_SrvAbbr(BR_CsvGet(parts, cols, "Server")))
                pth = LCase$(BR_Path(BR_CsvGet(parts, cols, "Path")))
                If sk <> "" And pth <> "" Then
                    gRecInv(sk & "!!" & pth) = "1"
                    bytes = BR_CsvGet(parts, cols, "Bytes")
                    If IsNumeric(bytes) Then gRecSizes(sk & "!!" & pth) = CDbl(bytes)
                    If IsElement(perSrv(sk)) Then perSrv(sk) = perSrv(sk) + 1 Else perSrv(sk) = 1
                    nRows = nRows + 1
                End If
            End If
        Loop
        Close #fh
        ageH = (Now - FileDateTime(dirPath & lf)) * 24
        If ageH > CfgL("RecoverMailListMaxHours", 48) Then BR_Log LVL_WARN, "Mail list " & lf & " is " & Format$(ageH, "0") & " h old: write a fresh one on the server (existence is still confirmed live before any create)"
    End ForAll
    ForAll ps In perSrv
        gRecInv("srv!!" & ListTag(ps)) = CStr(ps)
        info = info & ListTag(ps) & "=" & ps & " files; "
    End ForAll

' ---------------------------------------------------------------------
' Creates the mail file from the template ON THE HOME SERVER (template opened once per server, same server = no template
' data through the client) and WAITS until the copy is complete. HCL documents that CreateFromTemplate returns before a
' large copy has finished: without the wait the next steps (title, ACL, the next user) run against a half-copied file and
' several big copies pile up on the server. The wait is a poll for the ($Inbox) view every 2 s, up to RecoverCreateWaitSec.
' All object references are released before returning (the client has a limited number of handles).
' ---------------------------------------------------------------------
Function BRR_CreateFile(server As String, path As String, tmplName As String, title As String) As String
    On Error GoTo ErrH
    Dim mdb As NotesDatabase, v As NotesView, k As String, waited As Long, maxWait As Long, ready As Boolean
    k = LCase$(server & "!!" & tmplName)
    If gTmplDb Is Nothing Or gTmplKey <> k Then
        Set gTmplDb = gSession.GetDatabase(server, tmplName, False)
        If Not gTmplDb.IsOpen Then Call gTmplDb.Open("", "")
        If Not gTmplDb.IsOpen Then
            Set gTmplDb = Nothing
            gTmplKey = ""
            BRR_CreateFile = "MAIL_CREATE_ERROR(template " & tmplName & " not found on " & server & ")"
            Exit Function
        End If
        gTmplKey = k
    End If
    Set mdb = gTmplDb.CreateFromTemplate(server, BR_SrvPathFor(server, path), CfgB("MailInheritTemplate", True))
    maxWait = CfgL("RecoverCreateWaitSec", 120)
    Do
        Set v = Nothing
        On Error Resume Next
        Set v = mdb.GetView("($Inbox)")
        Err = 0
        On Error GoTo ErrH
        If Not (v Is Nothing) Then
            ready = True
            Exit Do
        End If
        If waited >= maxWait Then Exit Do
        Sleep 2
        waited = waited + 2
    Loop
    Set v = Nothing
    If Not ready Then
        Set mdb = Nothing
        BRR_CreateFile = "MAIL_CREATE_ERROR(copy not complete after " & maxWait & " s: no ($Inbox) view yet - the file may still be copying, run the agent again later)"
        Exit Function
    End If
    If title <> "" Then mdb.Title = title
    Set mdb = Nothing
    BRR_CreateFile = "MAIL_CREATED"
    Exit Function
ErrH:
    Set v = Nothing
    Set mdb = Nothing
    BRR_CreateFile = "MAIL_CREATE_ERROR(" & Error$ & " err " & Err & ")"
    Exit Function
End Function

' ---------------------------------------------------------------------
' Step 3: one pass over the files created in this run. Complete? Then request the cluster replicas in bursts
' (RecoverReplicaChunk, pause ChunkPauseSec) so AdminP and the cluster members are not flooded.
' ---------------------------------------------------------------------
Sub BRR_FinishCreated(db As NotesDatabase, nids() As String, n As Long, wantReplicas As Boolean, nVerOk As Long, nVerBad As Long, nRepReq As Long, nRepBad As Long)
    On Error GoTo ErrH
    Dim i As Long, doc As NotesDocument, u As BRUser, health As String, t0 As Double, chunkRep As Long, pause As Long, nSinceChunk As Long
    chunkRep = CfgL("RecoverReplicaChunk", 50)
    pause = CfgL("ChunkPauseSec", 5)
    For i = 0 To n - 1
        t0 = Timer
        Set doc = Nothing
        On Error Resume Next
        Set doc = db.GetDocumentByID(nids(i))
        Err = 0
        On Error GoTo ErrH
        If Not (doc Is Nothing) Then
            Call BR_LightUser(doc, u)
            health = BR_MailHealth(u.HomeServer, u.MailFile)
            If health = "OK" Then
                nVerOk = nVerOk + 1
                u.MailFileStatus = "MAILFILE_OK"
                u.ClusterReplicas = BR_ReplicaServers(u.HomeServer, "")
                If wantReplicas And u.ClusterReplicas <> "" Then
                    u.ReplicaStatus = BR_RequestReplicas(u)
                    If InStr(u.ReplicaStatus, "FAILED") > 0 Then
                        nRepBad = nRepBad + 1
                        Call BR_Audit(u, gMode, "RECOVER_REPLICAS", "FAILED", BR_Elapsed(t0), u.ReplicaStatus & " - repeat with RecoverCheckReplicas=1")
                    Else
                        nRepReq = nRepReq + 1
                        Call BR_Audit(u, gMode, "RECOVER_REPLICAS", "REPLICAS_REQUESTED", BR_Elapsed(t0), u.ReplicaStatus)
                    End If
                    nSinceChunk = nSinceChunk + 1
                    If chunkRep > 0 And nSinceChunk >= chunkRep And pause > 0 Then
                        nSinceChunk = 0
                        If i < n - 1 Then Sleep pause
                    End If
                End If
            Else
                nVerBad = nVerBad + 1
                u.MailFileStatus = "MAILFILE_INCOMPLETE"
                Call BR_Audit(u, gMode, "RECOVER_VERIFY", "FAILED", BR_Elapsed(t0), "Created, but completeness check says " & health & ". Replicas NOT requested. Run the agent again.")
                BR_Log LVL_ERROR, "Verify after create failed " & u.HomeServer & "!!" & u.MailFile & " : " & health
            End If
        End If
    Next
    Exit Sub
ErrH:
    BR_Log LVL_ERROR, "Finish pass stopped: " & Error$ & " (err " & Err & ", line " & Erl & ") - run the agent again with RecoverCheckReplicas=1 to request what is missing"
    Exit Sub
End Sub
